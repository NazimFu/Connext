# Homepage institution/company logos

Every image file placed directly in this folder shows up automatically in
the "Mentors from leading institutions" strip on the homepage — no code
changes needed. This is purely local and manually managed: unrelated to
mentor profiles, Google Drive, or any other external source.

## Adding or removing a logo

- **Add one:** drop an image file here (`.png`, `.jpg`, `.jpeg`, `.webp`,
  `.svg`, or `.gif`). It appears the next time the homepage loads.
- **Remove one:** delete the file.
- **Rename one:** rename the file — the display name shown on hover is
  always the filename with the extension stripped off, e.g.
  `Harvard Law School.png` shows as "Harvard Law School".

If this folder is empty, the homepage falls back to showing institution
name pills (e.g. "UTM") instead of logo images.
